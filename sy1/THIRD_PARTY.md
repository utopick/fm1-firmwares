# Third-party material

## oxo_synth2 (MIT)

`app/dsp/s1_tables.c` and `s1_tables.h` are generated by `tools/gen_tables.py` from oxo_synth2's
`EngineCore/MeasuredTables.hpp`, `Params.hpp` and `LegacyTables.hpp`: measurements of the original Synth1's
parameter laws, its parameter ranges and init values, and its conversion of old patch versions. The chorus
time table in `app/dsp/s1_fx.c` and the laws marked `(m)` in the engine's comments come from the same project's
`EngineCore/*.hpp`. The engine's code itself is written for this project.

https://github.com/chab/oxo_synth2

## Community preset banks

`app/site/library/` contains 27 original bank ZIPs (3,174 presets), selected from a user-supplied collection
where the accompanying notes explicitly allow redistribution. The source ZIP matches the file in the
[Internet Archive collection](https://archive.org/details/synth1_202202); the archive metadata credits the compilation
to **techno-addicts**. These presets are **separate from the MIT
source-code license**. Each original ZIP and its readme are preserved unchanged. Some authors prohibit
selling or including their patches in a paid library. See [bank credits](app/site/library/CREDITS.md),
[provenance](app/site/library/IMPORT.md), and the complete original notes in the catalogue and ZIPs.

Banks with absent, unclear or restrictive redistribution terms are not hosted. Users may import their
own full collection locally in the browser; it is not uploaded or redistributed by SY1.

## Included factory presets

`app/presets/factory500.h` embeds a 256-sound selection from the redistributable website banks. This
preset data is separate from the source-code MIT license, and remains under each patchmaker's own terms.
The selection's full author credits, terms and original readme text are in [CREDITS.txt](app/presets/CREDITS.txt)
and are embedded in program flash. The [downloadable factory ZIP](app/site/library/factory500.zip)
also preserves every selected `.sy1` file and all original source-bank `.txt` files byte-for-byte,
including the complete Lunatique readme required for redistribution. Banks that prohibit sale or
inclusion in a paid library retain those restrictions. SY1 distributes this bank free of charge.

The selection is generated by `tools/make_factory500.mjs` from the committed public bank ZIPs. Per-preset
source, author, original path and hashes are recorded in `app/site/library/factory500.json`.
