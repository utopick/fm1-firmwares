# Licensing

FM-1 ZX is free software under the GNU General Public License, version 3 or (at your option)
any later version (`GPL-3.0-or-later`, `LICENSE`). Some parts are other people's work under
their own licences. Our files carry an SPDX tag; each other part keeps its licence text beside it
(listed below), and `LICENSE` is the GPL's.

How a part is combined decides what it means for the whole:

- **linked into the image**: compiled and linked into `fmzx_app.bin`, the firmware the FM-1 runs;
- **separate program in the package**: shipped side by side in the update package, never linked
  with our code;
- **data**: bytes the firmware or the package carries and reads, not code linked with ours;
- **host tool**: runs on the developer's computer only; nothing of it is in the image or the
  package.

### The image

`fmzx_app.bin` combines our GPL-3.0-or-later code with LGPL-3.0-or-later, 0BSD and MPL-2.0 code
(felucca-bsp's hardware headers and its USB-MIDI device, update and flash code, linked), all
compatible with it; the image as a whole is under GPL-3.0-or-later. The source of every part
is this repository, so anyone given the image can rebuild it, also with a changed Z80 library
(LGPL-3.0 section 4). The ROM stays under Amstrad's permission, which covers it only unmodified.

### The update package

The `.fwsc` package is an aggregate of separate works, side by side in one container: the image
and the game pack (above), felucca-bsp's update loader (MPL-2.0; its complete source is
`platform/fm1/bsp/loader/` with the `chip/` and `boards/` files it includes) and the three SDK files (Apache-2.0). Whoever passes a
package on should pass on with it, or point to, this repository at the same commit (the source
of the GPL parts and the build of every byte), the licence texts (`LICENSE` for the GPL,
`third_party/Z80/COPYING.LESSER`, `third_party/Z80InsnClock/LICENSE-0BSD`, `platform/fm1/bsp/LICENSE`,
`third_party/zx-rom/LICENSING.md` and each game's in
`third_party/games/`), the SDK files' licence text (`docs/third-party/AC79-SDK-Apache-2.0.txt`;
`tools/make-packages` puts a copy, `AC79-SDK-Apache-2.0.txt`, next to the packages) and this file
with the games' attributions, and `third_party/games/` (each game's licence files, `COPYING.beeper`,
and ZX Sopwith's Corresponding Source `zxspectrum-sopwith-c1f39d2.tar.gz`). The Apache License covers
only the SDK files and `third_party/games/oneway/` (its `Wow.tap`, `LICENSE.release` and
`README.release.*`); the rest of the repository is not under it. A World of One-Way's repository has
no `NOTICE` file (checked at <https://github.com/Serdjuk/A-World-of-One-way> commit
`aecdf334f8c97eac2cd54052b73b0da06a38411e`: the only licence files are `LICENSE` and the beeper
engine's `COPYING`), so Apache-2.0 section 4(d) has nothing to carry over.

personal pack's recorded scores (BUILDING.md, "Arranged music"). It is optional, and what it
fetches stays on the computer that runs it: none of it is in the repository, the firmware image or
the packages. Its pieces, at the versions the
script pins, with their licences as their sources declare them:
